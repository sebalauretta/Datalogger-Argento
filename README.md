# Datalogger-Argento
Dispositivo de bajo costo y consumo energético que monitorea humedad, temperatura e iluminación, transmitiendo los datos vía Wi-Fi a una plataforma digital con registros históricos y alertas tempranas.De fabricación nacional (CEPyA-UNSAM),constituye un aporte al desarrollo de vitrinas inteligentes y sustentables para la conservación del patrimonio.
